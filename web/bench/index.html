这些数值怎么算？

TTFT 从发出请求算到首个含 token 的非空响应块。端到端时延从发送算到完成或失败。成功且两项耗时均小于或等于目标才算达标。

完成吞吐和达标吞吐分别用成功数、达标数除以相同的完整观测窗口秒数。P95 将成功请求按时延排序，取向上取整的第 95 百分位。失败与超时仍计入总请求数。
