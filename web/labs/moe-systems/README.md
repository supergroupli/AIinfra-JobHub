# MoE systems lab / MoE 系统工程实验

Python **3.9+**, standard library only. Extract the **whole** ZIP and enter `moe-systems` beside `lab.py`. Windows can replace `python3` with `py -3`. No GPU, accounts, model downloads or third-party packages are required for the required route.

只需普通 CPU 与 Python **3.9+**。完整解压后进入含 `lab.py` 的 `moe-systems` 目录。每一天都可以独立运行，命令不会依赖昨天的输出。

```bash
python3 --version
python3 lab.py day1 --out out
python3 lab.py day7 --skew 1 --out out/hot
python3 lab.py day7 --skew 1 --capacity-factor 2 --out out/hot-expanded
python3 lab.py day17 --out out
python3 lab.py day20 --out out
python3 check_exercises.py --reference
```

Reusing an output directory overwrites generated files of the same name. Keep comparisons in different directories. `day20` regenerates all twenty daily records and creates `REPORT.md` and `manifest.json`. It does not mark a student as having completed the course. Complete the report's TODOs yourself.

同名输出会被覆盖；对照实验用不同目录。第20天重跑全部日课并生成报告骨架与文件哈希清单，不会自动认定学员完成课程。本人需补齐假设、代码改动、解释与局限。

## What runs / 实际执行范围

- A deterministic four-expert, width-4 **linear CPU model**: routing, dispatch, expert computation and weighted combine. It is not a full gated MoE FFN and says nothing about model quality.
- An independent token-major direct oracle checks the bucket implementation without calling its dispatch or expert functions.
- Quantization is an explicit symmetric **INT8 teaching model, not FP8**. No GPU low-precision kernel is executed.
- **Day17 only** measures local Python CPU execution using `perf_counter_ns`, three warmups and seven raw samples. No fixed timing or speedup is promised.
- Bytes, bandwidth, capacity, padding, overlap and roofline values are declared analytical models. Times in these models are not observed GPU or network timings.
- No DeepEP, DeepGEMM, NCCL, CUDA, RDMA or distributed process is executed. [GPU_EXTENSION.md](GPU_EXTENSION.md) contains the separately labelled, pinned-source extension plan.

必做执行的是四个小型线性 CPU 专家及独立参照；不是完整模型。量化使用 INT8 教学近似；第17天仅测 Python CPU，其他成本值均来自明确的公式。没有上游 GPU 或网络运行结果。

## Exercises / 编程挑战

Implement `stable_topk` and `weighted_combine` in `exercises.py`. Then run:

```bash
python3 check_exercises.py
```

The original TODO file **must fail**. The independent checker includes negative scores, ties, shuffled contribution rows and empty tokens. It imports no lab implementation. Add your own boundary case. `reference.py` is an answer to inspect after attempting; `--reference` validates the supplied answer and does **not** grade your work.

初始 TODO 失败是预期行为。先独立实现，再读参考答案；补充一个自己的边界例。不能用 `--reference` 的通过记录冒充本人作业完成。

## Parameters and evidence / 参数与证据

`--tokens` 2–4096, `--topk` 1–4, `--skew` 0–1, `--capacity-factor` 0.1–8, `--bandwidth` 0.1–1000 **decimal GB/s**, `--seed` 0–1000000. Four experts and actual CPU width 4 are fixed; day12/14 explicitly model width4096. Wrong ranges and NaN are rejected. Output-file symlinks are rejected; choose a writable output directory separate from the source root.

固定四个专家、CPU向量宽度4；第12/14天另用4096作公式估算。参数与单位在 JSON 中记录。输入哈希标识生成的工作负载，源码哈希标识 `lab.py`；哈希不证明正确性或独立复现。第17天真实时间有波动，因此重复运行的输出哈希可能变化。

## Portfolio acceptance / 作品验收

1. Your two implemented functions pass the independent checker; submit a new explained edge case. / 本人函数通过检查，新增有解释的边界例。
2. Preserve all baseline records, input/source hashes and raw CPU samples. / 保留基线、输入源码身份及CPU样本。
3. Compare two placements under identical inputs and routes; explain a positive or negative result. / 相同输入路由比较两种布局，解释收益或退步。
4. Report both quantization metrics with predeclared tolerance; never describe INT8 simulation as FP8 hardware. / 报告两种误差及预定容差。
5. Complete `REPORT.md`; separate measured CPU values, analytical costs and unexecuted GPU plans. / 完成报告并明确三种证据类型。
6. A peer can extract the ZIP and rerun; timing variation is recorded rather than hidden. / 他人可干净解压复跑，记录时间差异。

Local validation on Python 3.9.6 ran all twenty day commands and the reference checker. This validates the bounded CPU exercise, not the learner's contribution or GPU performance.

本地 Python 3.9.6 已运行20日命令与参考检查，仅验证CPU实验，不等于学员认证或GPU结果。
