# 聘枢 · AI Infra JobHub 品牌与界面

聘枢连接知识、实践和职业机会。界面定位为清晰、可信、对新人友好的工程学习工作台：让人尽快找到一条路线、开始今天的任务，并留下别人能够理解的作品。

## 标志

图形由四条错位的 L 形线路与中央菱形组成。开放的线路代表不同背景的开发者与技术方向；中央菱形是“枢”，表示知识与机会在这里连接。四条线路的旋转节奏也表达持续学习，而不是一次性的速成。

| 文件 | 用途 |
| --- | --- |
| `web/assets/logo-mark.svg` | 导航、头像、favicon 等方形图标；全部为矢量路径 |
| `web/assets/logo.svg` | 浅色背景的中英文组合标志 |
| `web/assets/logo-light.svg` | 深绿背景上的反白组合标志 |
| `web/assets/logo-monochrome.svg` | 单色印刷或不支持彩色的场景 |

网站导航使用 mark + HTML 品牌名，便于中英切换、缩放和辅助技术识别。组合 SVG 的字标保留可访问文本，字体使用系统中文与无衬线字体；在没有这些字体的环境中，文字形态会略有差异。图形本身不依赖字体。

- 推荐网页 mark 尺寸 40px；页脚 36px；小图标不小于 24px，favicon 可缩至 16px。
- 图标四周至少留出图形宽度的 1/6 作为净空。
- 不拉伸、不倾斜标志，不在标志上叠加课程徽章或技术项目图标。
- 深绿底上使用反白版；浅底使用主版。保留中央菱形的对比度。

绿色强调只用于关键动作和状态。课程类别不只靠颜色区分，始终保留类别文字；完成状态同时提供图标或文字。

## 页面结构

首页首先说明“学习—作品—机会”的闭环。hero 保持适中，课程库紧接其后。三条职业路径提供选课起点；完整课程库支持技术、方向和硬件条件的筛选。卡片同时展示内容范围、时间安排、先修或硬件提示以及个人进度。

课程页采用“左侧十天目录 + 右侧阅读与实践”。正文具有足够行距，讲解、动手实践、交付物、验收和无硬件替代活动用一致的模块结构呈现。手机端目录可折叠，实践代码横向滚动，不把整页撑宽。

## 文字与可信度

- 标题写出技术和实际学习目标；“10 天”表示一轮有边界的学习安排，不等于生产级精通。
- 课程引用官方资料并记录核对日期；实验结果必须说明环境和限制。
- 不展示虚构学员数、就业结果、招聘方或评分。
- 学习进度是浏览器内的自我记录，不能把勾选包装成能力认证。
- 求职简历邮箱与自愿公开的作品名片保持清楚区分。

## 可访问性与动效

主色与背景保留清楚对比；交互控件具有可见的键盘焦点。按钮和表单保留明确名称。减少动效偏好的用户不触发滚动或悬停动画。界面不依赖大图、外部字体、追踪脚本或 GPU 动画，便于全球低带宽访问。
