# 首页访问地球

首页社区区域上方展示可暂停的旋转地球。当前已配置发起者提供的公开 MapMyVisitors 3D Globe 代码。`—` 表示没有可用数据，不表示零访问。系统开启「减少动态」时，默认保留本地静态示意，用户可主动载入统计；离开可视区域或隐藏标签页后暂停动画。

2026-11-14 的源码核对确认官方 script ID 为 `mmvst_globe`，地球由 CSS/SVG 绘制，并依赖旧版 jQuery 与 Velocity。组件被放在独立 sandbox iframe 内，使用其正常页面加载生命周期，不向本站注入这些全局库。框架不授予同源权限，不读取学习笔记。

这次只读核对中，官方数据回调返回 HTTP 200 的 HTML，未取得预期 JSONP 或有效 `/web/` 统计页，因此尚未确认真实访问数据。配置的 `statsUrl` 保持 `null`；只有实际组件出现可见 SVG 时才显示组件，超时则回退到明确标注的本地地球示意。iframe 加载完成不作为统计成功的证据。若组件后续提供合法官方统计页链接，页面会显示该入口。

## 接入真实访问统计

项目不需要自建服务器。更换站点或账号时，维护者使用自己的 MapMyVisitors 账号，为 `https://supergroupli.github.io/AIinfra-JobHub/` 创建站点，在 [官方添加页面](https://mapmyvisitors.com/add) 选择 3D Globe，取得公开嵌入代码与可用时的公开统计页地址。

只需要公开代码，不需要密码或私密 API 密钥。将嵌入代码里的脚本 URL 与统计页 URL 填入 `web/visitor-globe-config.json`：

- `version` 保持整数 `1`。
- `provider` 从 `null` 改为 `"mapmyvisitors"`。
- `scriptUrl` 为官方生成的 `https://mapmyvisitors.com/globe.js?...` 地址。
- `statsUrl` 为对应的 `https://mapmyvisitors.com/web/<站点标识>` 地址；尚未确认时保留 `null`，不要猜测。

若从 HTML 属性复制 URL，先将 `&amp;` 解码为 `&`。不要把整段 HTML、账号凭据或其他脚本粘进配置。不要猜测 `d` 参数或使用他人站点的标识。脚本只接受官方 HTTPS 域名、固定路径和受限的展示参数；若提供方格式发生变化，应先核对官方代码，再调整验证器。

配置完成后运行 `node --test tests/visitor-globe.test.cjs` 和 `python3 scripts/build.py`，推送到 `main`。部署后检查真实浏览器与提供方统计页；脚本下载成功不等于数据已收到，出现展示区域也不证明数值已核验。减少动态模式默认不加载第三方地球，访客可点击按钮自行加载。

## 统计口径与范围

首页显示官方地球组件，其计数和国家分布由提供方呈现；同时提供查看公开统计页的入口。本站不爬取第三方 DOM 或猜测计数，不将组件加载状态包装成真实数据。加载失败会保留地球示意并提供重试。

统计仅覆盖已接入脚本的公开页面：首页、课程、入门自查、知识库、故障案例、练习、实战项目、求职准备和人才速览。其他这些公开页面使用 [官方文档](https://mapmyvisitors.com/learn/tools/add-a-visitor-map-widget/) 描述的图片端点计数；首页只加载一次地球，不再额外加载计数图片。投递记录、招聘草稿、作品编辑和搜索页面不加载统计脚本。

展示名称为「公开页面访问量」，不是在线人数、注册人数或独立学员数。重复访问、机器人过滤、去重、统计周期与国家划分，以提供方说明为准；接入前的历史流量不能追溯。IP 地理定位只是近似来源，代理和 VPN 会影响结果。

启用后，访客浏览器向 MapMyVisitors 发出请求。根据其 [隐私政策](https://mapmyvisitors.com/b/policy)，提供方会处理 IP 等访问数据；不能宣称「不收集 IP」。本站的加载器不读取笔记、表单或投递记录；官方组件在页面中的后续请求行为仍由提供方控制。已提供政策链接，并在首页隐私说明中说明启用后的处理方式。

## 暂停与撤下

将 `provider`、`scriptUrl`、`statsUrl` 全部恢复为 `null`，重新构建部署即可停止后续外部统计请求，回到本地地球示意。此状态只读取本站配置，不加载外部脚本或计数图片，不制造访客光点或数量。若需删除已积累的数据，应在提供方账号内管理。
