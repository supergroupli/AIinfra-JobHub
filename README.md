# 聘枢

<img src="web/assets/logo-mark.svg" width="64" height="64" alt="聘枢标志">

**AI Infra JobHub · 学习、做作品、找到同行。**

聘枢是一个免费、开放、面向全球 AI Infra 开发者的学习与职业成长社区。我们把技术学习、工程实践、作品展示和工作机会连接起来，帮助刚入门的同学迈出第一步，也让工程师与招聘团队通过具体的作品认识彼此。

**[进入聘枢](https://supergroupli.github.io/AIinfra-JobHub/) · [开始学习](https://supergroupli.github.io/AIinfra-JobHub/#learn) · [探索实战项目](https://supergroupli.github.io/AIinfra-JobHub/projects/) · [加入社区交流](https://github.com/supergroupli/AIinfra-JobHub/discussions)**

## 从学会一个概念，到做出一份作品

AI Infra 的成长需要读懂原理，也需要亲手运行、观察结果、定位问题。聘枢围绕这条路径组织内容：

- **有路线地学习。** 按推理工程、性能工程、平台工程和后训练工程选择必修与选修课程，用中英双语讲解、直观图解和交互演示理解系统。
- **动手做出成果。** 跟着实验步骤运行代码，处理常见报错，再完成自己的项目，留下代码、实验记录和技术复盘。
- **带着作品连接机会。** 整理作品档案、准备求职、记录投递；招聘团队可以描述工程需求、查看自愿公开的作品名片，发起进一步交流。

## 让作品成为交流的起点

一份可复现的基准测试、一篇源码解读、一个独立项目，都值得被看见。

求职者可以用作品说明自己解决了什么问题、如何验证结果，再与合适的团队交流。招聘者可以把岗位里的工程问题、必需技能和协作条件讲清楚，让双方更容易判断是否适合。

简历投递：**[career@yzinfra.com](mailto:career@yzinfra.com)**。可附上目标方向、工作地区、远程偏好和公开作品链接。邮件简历不会自动发布到 GitHub；公开作品名片由本人另行选择提交。

学习进度、笔记与求职草稿保存在当前浏览器，重要内容请使用相应工具导出备份。
